Utiliser principalement les composants shadcn/ui pour le frontend RestoRouen.

**Why:** C'est la lib UI choisie pour le projet front.

**How to apply:** Toujours préférer les composants shadcn (Button, Input, Table, Card, etc.) plutôt que du HTML brut ou d'autres libs UI pour le projet front.
