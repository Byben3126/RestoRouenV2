Le mapper est un élément crucial souvent mal compris. Laisse-moi t'expliquer son rôle.
C'est quoi un Mapper ?
Un mapper est une classe qui convertit des données d'un format à un autre. C'est le traducteur entre tes différentes couches.
Pourquoi on en a besoin ?

Il y a plusieurs représentations du même concept "Worker" :
Entity (ton objet métier)
DTO (ce qui entre/sort de l'API)

Le mapper fait les conversions entre ces formats.
